# ИИ-Анализатор отзывов на базе Orbitr

Веб-приложение на базе Streamlit для автоматического анализа тональности отзывов русскоязычных пользователей.

Интерфейс реализован на базе Streamlit.

https://orbit-reviews-4t2kg7ed6xjappw9nfckdyx.streamlit.app/

## Стек технологий
- Python 3.9+
- Streamlit
- Pandas
